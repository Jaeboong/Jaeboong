# HearBe — 시각장애인 음성 쇼핑 지원 서비스

> 이미지와 복잡한 결제 절차 때문에 온라인 쇼핑이 어려운 시각장애인을 위한 음성 기반 쇼핑 지원 서비스

- **개발 기간**: 2026.01.07 – 2026.02.09
- **인원**: 7명
- **역할**: AI 파트 · 음성 명령 의도 분류와 NLU 파이프라인
- **Repository**: [Jaeboong/hearbe](https://github.com/Jaeboong/hearbe)

## 문제

온라인 쇼핑은 이미지 중심의 상품 정보와 여러 단계의 결제·인증 절차로 구성돼 있습니다. 화면을 읽는 것만으로는 현재 상태와 다음 행동을 파악하기 어렵고, 음성 명령이 매번 모델 추론을 거치면 반응이 느려질 수 있습니다.

## 해결 방식

자주 사용되는 명령은 규칙 기반으로 즉시 처리하고, 문맥 해석이 필요한 명령은 KoELECTRA 의도 분류 모델로 전달하는 하이브리드 NLU 파이프라인을 설계했습니다.

```text
음성 명령
   ├─ 명확한 즉시 응답 → Rule-based
   └─ 문맥 해석 필요   → KoELECTRA Intent Classification
                              ↓
                         쇼핑 동작 실행
```

## 담당 내용

- 회원가입·로그인·상품 탐색·결제·환불 등 쇼핑 명령 의도 체계 정의
- 한국어 음성 명령 데이터 전처리와 KoELECTRA 파인튜닝
- Hugging Face Transformers Trainer 기반 학습·평가
- 규칙 기반 응답과 모델 분류를 연결한 NLU 흐름 구현

## 결과

- 의도 분류 평균 응답시간 **23ms** 달성
- 단순 명령은 모델 호출 없이 즉시 처리해 불필요한 지연 감소
- 처음 맡은 AI 영역에서 데이터·모델·서비스 연결까지 완수
